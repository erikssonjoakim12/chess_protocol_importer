🔒 Keep your key safe

Your key is like a password to your Google account's Gemini use. The free tier costs nothing, but if billing is ever switched on (for example to use a paid model), a leaked key could cost money. Five steps, the first is the important one:

  1. Lock the key to this app. Then a copied key is useless anywhere else.
    1. Open Google Cloud → Credentials with the same Google account, and click your key.
    2. Under Application restrictions choose Websites and add (and, if you also run the app on your own computer, http://127.0.0.1:8000/*).
    3. Under API restrictions choose Restrict key, tick Generative Language API, and Save.
  2. Never share it, post it, or put it in a screenshot. This app only ever shows its first and last four characters.
  3. On a shared or borrowed device, press Remove above when you're done.
  4. If you switch on billing, set a budget with e-mail alerts in Google Cloud (Billing → Budgets & alerts), so unexpected use can't go unnoticed.
  5. If you think the key has leaked, delete it in Google AI Studio, create a new one and paste it here.

The key is stored only in this browser on this device and sent only to Google. On the free tier, Google may use what you send to improve its products.
